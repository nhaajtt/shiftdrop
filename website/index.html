FAQ (not very serious)

Is ShiftDrop free?

Yes, 100% free and open source (MIT). There is no secret Pro version.

Do my files get uploaded?

No. Everything runs on your PC. Only actions that say so, like “To phone” or “Translate”, use the network, and only when you pick them.

Why does Windows warn me?

It is a new app without a paid code-signing certificate, so SmartScreen hasn't met it yet. Choose More info → Run anyway. The source is public on GitHub.

Video and audio don't work?

They need the free FFmpeg add-on: Settings › Add-ons › Download. One time.

Is there a Mac version?

Planned. For now it is Windows 10 and 11.

Where is the app after installing?

It lives quietly in the system tray (the ⇄ icon by the clock). No window to keep open; just drag a file and hold Shift.
