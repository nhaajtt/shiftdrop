Every kind of file gets its own wheel

▣

Images

Convert (HEIC and RAW too), compress, crop, add a background, copy text (OCR), read QR, icons and favicons, watermark, trace to SVG, remove background, blur faces, upscale.

▶

Video

Fit to 8/25/50 MB, convert, trim, merge, extract audio, speed, flip, thumbnails, clean up sound, subtitles from speech.

▤

PDF

To images, compress, split, merge, rearrange pages, sign, page numbers, watermark, text (scans too), passwords.

W

Documents and data

Word, Excel, PowerPoint to PDF; Markdown to Word; JSON, YAML, TOML, XML, CSV; compare two files; translate and summarise.

⛨

Security

Spots files like invoice.pdf.exe, checks signatures, hashes, VirusTotal by hash, encrypts, shreds, shows what is locking a file.

⌬

Developers

Open programs in x64dbg, IDA, Ghidra; PE report with imphash and entropy; capa, FLOSS, UPX; copy paths as WSL or Markdown.

Gets better the more you use it

Learns your habits

What you use climbs onto the wheel. The rest is one search away under More.

Recipes

Chain steps into one drop: resize, to JPG, remove metadata.

Watched folders

New files in Downloads or Screenshots get processed on their own.

Shelf

Collect files from different folders, drag them out together.

Quick look

Ctrl + Space in Explorer previews images, video, PDFs, text.

To your phone

Scan a QR code to download over your Wi-Fi. The link expires.

Private by design

Everything runs on your PC. No account, no tracking. Only the actions you choose reach the internet, and each one says exactly what it sends.

  • VirusTotalsends only the SHA-256, never the file
  • Translate / Summarizeuses your own Claude API key
  • To phoneyour local network only, 10 minutes
  • Add-onsdownloaded from official releases when you ask
  • API keysencrypted with Windows DPAPI

Install in a minute

  1. Download the installer above and run it. No admin rights needed.
  2. If Windows says “Windows protected your PC”, choose More info → Run anyway. It is a new app without a paid code-signing certificate yet.
  3. ShiftDrop lives in the system tray. Start dragging a file, then hold Shift.
